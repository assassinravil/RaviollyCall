# Видеозвонок 1 на 1 без своего сервера

Камера, микрофон и демонстрация экрана. Ничего устанавливать не нужно: это обычные файлы,
которые можно бесплатно разместить на GitHub Pages.

## Как это работает

- Чтобы два браузера нашли друг друга, используются **сразу несколько** бесплатных публичных серверов MQTT.
  Если какой-то недоступен (например, заблокирован в вашей сети), хватит любого одного.
  Через них идут только короткие служебные сообщения в начале звонка, **зашифрованные** ключом из ссылки на комнату.
- Комната нигде не хранится: пока в ней кто-то есть, она существует, все вышли — от неё ничего не осталось.
- Видео и звук идут **напрямую между браузерами**, в зашифрованном виде.
- Если сеть не даёт соединиться напрямую, трафик автоматически пойдёт через бесплатный ретранслятор (TURN) от проекта PeerJS.

## Обновление уже выложенной версии

Если вы уже выкладывали прошлую версию: в репозитории удалите `peerjs.min.js`, затем через
**Add file → Upload files** загрузите новые файлы с заменой. Через минуту-две обновите страницу на телефоне.

## Размещение на GitHub Pages (только через сайт, без программ)

1. Зайдите на github.com, нажмите **New repository**. Придумайте имя, например `call`, выберите **Public** и нажмите **Create repository**.
2. На странице репозитория нажмите ссылку **uploading an existing file**.
3. Перетащите в окно **все файлы из этой папки**: `index.html`, `app.js`, `config.js`, `mqtt.min.js`, `style.css`.
   Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе *Branch* выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сверху появится адрес вида `https://ВАШ_ЛОГИН.github.io/call/`. Это ваш сервис.

Дальше откройте адрес, нажмите «Создать комнату», войдите и отправьте ссылку собеседнику.

> Если открыть `index.html` двойным кликом прямо с компьютера, страница тоже может заработать,
> но собеседник по такой ссылке не попадёт. Для настоящих звонков нужен адрес с GitHub Pages.

## Возможности

- Комната по ссылке. Неважно, кто зайдёт первым.
- Включение и выключение микрофона и камеры.
- Демонстрация экрана (на компьютере; мобильные браузеры её не поддерживают).
- Если собеседник вышел, он может вернуться по той же ссылке.
- Третьего человека в комнату не пустят: он увидит сообщение «уже идёт звонок».

## Ограничения бесплатного варианта

- Публичные серверы бесплатные и без гарантий. Внизу экрана ожидания видно, к скольким из них удалось подключиться
  («Серверы связи: 3 из 4»). Если 0 — сеть блокирует их все, попробуйте другую сеть.
- Если связь есть, но звонок не соединяется, — сеть одного из участников блокирует прямое соединение и бесплатный TURN.
  Поможет другая сеть или свой TURN-сервер в `config.js`.
- Любой, у кого есть ссылка на комнату, может в неё зайти. Не публикуйте ссылку открыто.
- Если нужна надёжность, можно поднять свой MQTT-сервер и свой TURN и прописать их в `config.js`.

## Файлы

```
index.html     — страница
style.css      — оформление
app.js         — логика звонка
config.js      — настройки (обычно менять не нужно)
mqtt.min.js    — библиотека MQTT.js 5.16.1 (лежит рядом, чтобы не зависеть от внешних CDN)
```
